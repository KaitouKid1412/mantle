# Plan 09 evidence

Engine passthrough rows (code E) share one path in mantle: the engine's command list
(initialize `commands`, `system/init` `slash_commands`, `commands_changed`) becomes the /
menu's engine entries, and a slash command that no native command claims is sent to the
engine as prompt text, where the engine runs or expands it. That path is covered by
`features/input` TestEngineCommandsPublished (initialize, init and commands_changed become
`ext.CommandsMsg` entries with no Run) and TestSlashRouting (engine and unknown commands go
to the engine as text, native ones run locally), and side by side against Claude Code by
the `compact` and `context` scenarios in `test/parity/scenarios` (engine local commands run
through mantle). Which commands the engine offers headlessly was checked with zero-token
control-request spikes (initialize only, no prompt) on 2.1.288 and 2.1.289; see "Facts
verified (Part B)" in docs/plans/09-ecosystem-panels.md.
